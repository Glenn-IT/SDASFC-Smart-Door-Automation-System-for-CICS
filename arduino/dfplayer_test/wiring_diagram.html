MP3-TF-16P Hardware Pin Connection Reference
MP3-TF-16P Pin Function Target Connection Wire Color Notes
Pin 1 (Top Left) VCC (Module Power) ESP32 5V (VIN) Red 5V Power Input (Add 100uF Cap to GND)
Pin 2 (2nd Left) RX (Data Input) ESP32 GPIO 17 (TX2) Cyan ⚠️ Connect through 1kΩ Resistor!
Pin 3 (3rd Left) TX (Data Output) ESP32 GPIO 16 (RX2) Blue Direct Serial connection
Pin 6 (6th Left) SPK1 (Audio Output +) Speaker Lead (+) Amber 3070 3W 8Ω Speaker Output 1
Pin 7 (7th Left) GND (Ground) ESP32 GND Black / Slate Common Ground connection
Pin 8 (Bottom Left) SPK2 (Audio Output -) Speaker Lead (-) Yellow 3070 3W 8Ω Speaker Output 2

⚡ Anti-Brownout Capacitor & 1kΩ Resistor Notes

100µF Capacitor: Place across Pin 1 (VCC) and Pin 7 (GND) of the MP3-TF-16P module to absorb startup current spikes and eliminate ESP32 flash read err, 988 boot loops.
1kΩ Resistor: Placed in series between ESP32 GPIO 17 (TX2) and MP3-TF-16P Pin 2 (RX) to protect the RX pin and eliminate background static/popping noise.

Serial Monitor Interactive Commands (115200 Baud)

Open Arduino IDE Serial Monitor, select 115200 baud, and type these commands:

1
Play 0001.mp3 System Ready / Welcome prompt
2
Play 0002.mp3 Access Granted prompt
3
Play 0003.mp3 Access Denied prompt
+
Volume Up Increases volume (+2 steps)
-
Volume Down Decreases volume (-2 steps)
